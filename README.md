## contents

**cifar10-ann** — fully connected neural networks on CIFAR-10 dataset, exploring
how depth, learning rate, and activation functions affect performance. built with PyTorch.

**algorithms-from-scratch** — KNN, K-Means, and HAC implemented in pure
NumPy, without any ML libraries.

**svm-exploration** — SVM experiments with sklearn covering kernel comparison,
hyperparameter tuning, and class imbalance handling strategies.
